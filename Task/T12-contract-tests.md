### 2. Новые тесты

**`teacher_test.go`** — полный цикл преподавателя:
- `inviteToken` в регистрации выдаёт роль `teacher`; без токена — `student`;
- не-учитель получает `403` на `/teacher/courses`;
- создание курса → 201, авто-slug вида `course-xxxxxxxx` если slug не задан;
- `submit` без модулей/уроков → `400`;
- с модулем и уроком → `200`, `status: review`;
- чужой курс → `403` при добавлении модуля;
- валидация урока по `kind`: `quiz` без вопросов → 400;
  `quiz` с `correct` вне диапазона → 400; `code` без тестов → 400;
  несуществующий `moduleId` → 400.
- **важно:** проверь, что `correct`-ответы квиза **не утекают**
  в `GET /courses/{slug}` для анонимного (как в `courses_test.go:125-127`).

**`admin_test.go`** (новый) — модерация и приглашения:
- очередь возвращает только курсы в `review`;
- `approve` → `published`; `reject` без комментария → `400`;
  `reject` с комментарием → `draft` + непустой `moderationComment`;
- повторная модерация → `400`;
- `POST /admin/invites` выдаёт токен, и он **работает** в регистрации;
- студент на `/admin/*` → `403`.

**`admin_payments_test.go`** — US6 (зависит от T07):
- журнал пуст на старте; после покупки — 1 запись;
- фильтр по `status`; фильтр по `courseId`;
- `total` не зависит от `page`;
- `totals.amountCents` = сумма строк выборки;
- `PUT /admin/settings` меняет комиссию и она применяется к **новой** покупке;
- `commissionPct` вне `0..90` → `400`;
- студент → `403` на оба эндпоинта.

**`auth_hardening_test.go`** (зависит от T10):
- cookie подписана: подмена последнего символа → `401`;
- `SESSION_SECRET` действительно влияет на значение;
- rate-limit: N+1 запрос на логин → `429` + заголовок `Retry-After`;
  и что лимит **общий** для двух тестовых серверов или явно сбрасывается
  (иначе тесты будут зависеть от порядка).

**Дополнительно покрой то, что не покрыто:**
- `/auth/logout` → `204`, после него `/auth/me` → `401`;
- пагинация: `limit > 100` обрезается до 100; `page = 0` → первая страница;
- CORS: чужой Origin не получает `Access-Control-Allow-Origin`;
- лимит тела запроса (1 МБ).

### 3. `qa-abc.ps1`

Скрипт на PowerShell, который поднимает проверки **против запущенного стенда**
(`http://localhost:8082`), без зависимостей. Требования:
- параметры: `-BaseUrl`, `-WebUrl` со значениями по умолчанию;
- обёртка `Invoke-Check` с накоплением результатов и цветным выводом;
- сценарий: регистрация → вход → каталог → страница курса →
  покупка (mock) → вебхук → доступ к урокам → прохождение квиза →
  отзыв → повторный отзыв (409) → выход → `401`;
- **идемпотентность:** каждый запуск использует уникальный email
  (`qa-<timestamp>@example.test`), чтобы скрипт можно было гонять повторно;
- код возврата: `0` — все проверки прошли, `1` — есть падения;
- заголовок файла на русском с инструкцией по запуску.
