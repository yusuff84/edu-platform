# T39 — Обучение: следующий урок и финиш курса (frontend)

**Волна:** P4 · **Ветка:** `task/T39-learn-finish` · **Worktree:** `wt/t39`

## Зачем

На странице обучения после **успешно** прошедшего урока ученик не получает ни кнопки «дальше»,
ни признания, что курс закончен: ссылка «продолжить» есть только при провале (`Learn.tsx:404`),
а при `percent === 100` экран выглядит как обычный урок. Последний шаг воронки ученика обрывается.

## Что сделать (`frontend/src/pages/Learn.tsx`, словарь уже пополнен)

1. После успешного вердикта (`verdict?.passed`) — кнопка/ссылка «Следующий урок»
   (`learn.nextLesson`) на следующий урок:
   - сначала серверный `progress.nextLessonId` (если он есть среди уроков курса);
   - иначе линейный следующий (`flatNext`) — как уже сделано для случая провала;
   - в самом конце курса (следующего нет) кнопки нет.
2. Панель завершения курса, когда `progress.percent === 100`:
   - заголовок `learn.courseFinished`, текст `learn.finishedHint`;
   - кнопка `learn.leaveReview` → страница курса `/courses/{slug}` (там форма отзыва);
     `slug` — из `meCourse.course.slug` (если его нет — ссылка на `/me` с текстом `common.back`);
   - панель не должна мешать читать уже пройденный урок: размещать её **над** блоком урока и
     не прятать навигацию по урокам.
3. Прогресс/`completedLessonIds` по-прежнему только с сервера (`course-progress`) —
   никаких локальных «дорисовок» процента, это требование T30.
4. Не ломать: провал теста и текст ошибки, состояния загрузки/ошибки/отсутствия доступа,
   `sr-only`-метки, разметку сайдбара.
