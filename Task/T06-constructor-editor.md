# T06 — Конструктор курса: редактирование, порядок, обратная связь

**Ключ сессии:** `T06-constructor-editor`
**Волна:** 2 (после T01, T02) · **Слой:** frontend
**Приоритет:** P1 — FR-008 (`spec.md`) не реализован

## Проблема

`frontend/src/pages/Constructor.tsx`:

- `:48-54` — `detailQuery` зависит от `findSlug()`, который читает
  `teachingQuery.data?.find(...)`; из-за конверта `{ items, total }` (T01)
  `findSlug()` всегда `undefined` → **редактирование существующего курса
  не загружается вообще**;
- `:140-219` — можно только **создать** модуль и урок; нельзя
  изменить, удалить, переставить ни то, ни другое;
- `:84-88` — при создании урока не отправляются `bodyMd`, `quiz`, `codeTask`,
  `liveUrl`, `startsAt` → после исправления клиента форма всё равно
  не даёт заполнить контент урока (FR-008);
- `:199-213` — список уроков только для чтения;
- `:143` — комментарий модератора (`moderationComment`) **не показывается**
  преподавателю после отклонения — преподаватель не понимает, что исправлять;
- нет состояний загрузки/ошибки, нет подтверждения удаления.

## Что сделать

1. **Починить загрузку существующего курса.** После T01 `myTeaching()` —
   массив. Находить курс по `id` из URL. Никаких «slug-одгаданий».
2. **Список моих курсов** (`/teach`): карточки со статусом
   (`draft` / `review` / `published` / `archived`), ценой, числом модулей
   и уроков; кнопка «редактировать», «на модерацию» для черновиков.
3. **Модули:**
   - создание (уже есть);
   - переименование — через повторный `POST` с тем же заголовком **нельзя**
     (создаст новый), поэтому показывай это как известное ограничение,
     а в UI — «переименование потребует поддержки API» либо реализуй
     оптимистичное локальное изменение с честной пометкой. **Выбери одно
     и опиши в отчёте.**
   - удаление и изменение порядка — аналогично, по ограничениям API.
   Всё, что API не поддерживает, **не рисуй как рабочую кнопку** —
   лучше честное «скоро» или отсутствие.
4. **Создание урока — полная форма по `kind`:**
   - `video_text`: `title`, `bodyMd`, `videoUrl` (хотя бы одно из двух — иначе 400);
   - `live`: `title`, `liveUrl` (обязательно), `startsAt`;
   - `quiz`: динамический список вопросов — текст, 2+ варианта,
     выбор правильного, пояснение. Перед отправкой показать счётчик вопросов.
   - `code`: выбор `language` (`python|js|htmlcss`), `template`,
     список тестов (`name`, `input`, `expected`, флаг `hidden`).
     Валидация: минимум 1 тест, иначе backend вернёт 400.
   - Собирать тело **только из релевантных kind полей** —
     `DisallowUnknownFields` отвергнет лишние.
5. **Обратная связь модератора:** баннер наверху конструктора, если
   `status === 'draft' && moderationComment` — текст комментария админа.
   Это то, что делает цикл «отклонили → исправил» рабочим.
6. **Кнопка «на модерацию»** (`submitCourse`) — только для `draft`,
   с пояснением, что после отправки контент нельзя менять до решения,
   и `confirm`-диалогом. Обработать `400` с пояснением причины.
7. **Состояния:** загрузка, 404 «курс не найден», 403 «не ваш курс»,
   ошибка сети, успешное сохранение (toast/подпись), пустая программа.
8. **Клавиатура:** формы на `<form onSubmit>`, `label` у всех полей,
   фокус на первое ошибочное поле.

## Критерии приёмки
