## 1. Сверь контракт с фактом

Открой `Task/00-api-contract.md`, раздел «Расхождения, найденные агентами» —
там **8 пунктов**. По каждому убедись, что:
- тест фиксирует **фактическое** поведение (не желаемое);
- описание в контракте совпадает с кодом.

Особое внимание:
- **№4** (`startsAt`) — у T16 есть тест-фиксатор `TestStartsAtNotPersistedDiscrepancy4`,
  который он должен обновить после починки. Проверь, что он не остался
  падать и не был просто удалён (удаление — не тестирование).
- **№8** (`register` → 400, а не 409) — контракт должен говорить 400.

## 2. Покрой недостающее

Найди дыры, а не добавляй тесты «для галочки». Кандидаты (проверь сам):
- `SetEnrollmentStatus` — смена статуса в **обоих** сторах, `ErrNotFound`;
- `ListPaymentsJournal` — фильтры по статусу/курсу, `totals` без учёта пагинации,
  `items != null` при пустой выборке, `limit` клампинг 20..100, 1→100;
- `PUT /admin/settings` — диапазон 0..90, неизвестные поля → 400;
- вебхук `refunded` → `EnrollmentRefunded`;
- rate-limit: `429` + `Retry-After`, `<=0` выключает лимитер;
- подпись cookie: подделка → 401, `Secure` при `X-Forwarded-Proto: https`;
- Yandex OAuth: сверка `state` (constant-time), 503 без `YANDEX_CLIENT_ID`;
- runner: общий бюджет времени, лимит вывода, `503` при переполнении семафора;
- **новые эндпоинты T16** (revoke) и **T19** (CRUD конструктора) — если
  T19 уже написал тесты в `teacher_crud_test.go`, дополни, а не дублируй.

## 3. Качество тестов — требования

- `-count=1`, без кэша;
- **без обращения в сеть** — только `httptest`;
- **детерминированно** — время инжектируй, не `time.Now()` напрямую;
- каждый тест строит свой `App`/store (паттерн `helper_test.go`);
- **не ломай** идемпотентность вебхука и сплит комиссии 1500/8500 — это
  регресс-якоря;
- названия говорящие, комментарии **по-русски**;
- `-race` обязателен для конкурентного кода (лимитер, HMAC, store-мьютексы):
  alpine → `apk add gcc musl-dev`, `CGO_ENABLED=1`.
