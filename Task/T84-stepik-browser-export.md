# T84 — Получение курса Stepik через браузер

Курс: «Цифровая гигиена», https://stepik.org/course/146168.

Собранная структура: 9 разделов, 23 урока, 83 шага — 18 видео, 20 текстовых шагов и 45 заданий. У заданий 33 шага с выбором ответа, 2 с таблицей, 7 на сопоставление, 2 с пропусками и 1 на сортировку. Число 82 в показателе Stepik означает баллы, а не количество шагов.

## Использование

Зависимости берутся из установленного Playwright во frontend. Прямые запросы к API Stepik не используются: скрипт открывает обычные страницы и читает отрисованный DOM.

```powershell
node scripts/stepik-browser-export.cjs --login
# Войти в Stepik в открывшемся окне, затем закрыть окно.
node scripts/stepik-browser-export.cjs
node scripts/stepik-materialize.cjs
```

Профиль браузера хранится отдельно от репозитория: `%LOCALAPPDATA%/CodexStepikBrowser`. Его нельзя добавлять в Git. При необходимости путь задаётся переменной `STEPIK_BROWSER_PROFILE`.

Результат находится в `.local/stepik-146168/` (исключён из Git). `STEPIK_EXPORT_DIR` позволяет изменить каталог для обоих скриптов.

- `manifest.json` — разделы, уроки, порядок шагов, ссылки на оригиналы и ошибки получения.
- `steps/*.json` — текст, очищенный HTML, условия и варианты заданий, ссылки на медиа.
- `assets/`, `assets.json`, `media-summary.json` — скачанные видео и изображения, размеры и ошибки. Выбирается максимальное разрешение видео из источников, указанных в DOM. Загрузки идут по обычным адресам медиафайлов.
- `index.html` — локальная версия для просмотра, без JavaScript и отправки ответов.
- `course.md` — текстовая сводка; исходное форматирование и таблицы сохранены в HTML/JSON.

Скрипт не отправляет ответы, не извлекает скрытые ключи проверки и не собирает комментарии учеников. Повторный запуск использует сохранённые шаги и завершённые медиафайлы. При неполном экспорте или ошибках код завершения ненулевой.

## Импорт в платформу

Курс импортирован в рабочий локальный стенд `edu-review`, опубликован бесплатно:

http://127.0.0.1:13001/courses/cifrovaya-gigiena

В родной структуре платформы создано 9 разделов и 83 шага обучения из 23 исходных уроков. Все 18 видео 720p и 42 изображения размещены в постоянном томе uploads API: `/uploads/imports/stepik-146168/`. Авторство, источник, лицензия исходных материалов и описание адаптации указаны в карточке курса; каждый шаг ссылается на оригинал. Другая локальная установка на порту 3001 не изменялась.

```powershell
python scripts/import-stepik.py --prepare-only
python scripts/import-stepik.py
```

Импортёр проверяет целостность локальных файлов и наличие всех шагов, копирует медиа и выполняет вставку курса в одной транзакции. По умолчанию используются контейнеры `edu-review-db-1` и `edu-review-api-1`; можно явно задать `--db-container`, `--api-container`, `--db-user`, `--db-name` и `--teacher-id`. При отсутствии `--teacher-id` владельцем назначается первый активный администратор, затем преподаватель. Стабильные UUID и вставка без перезаписи сохраняют существующие правки и прогресс при повторном запуске. Материалы курса не вшиты в миграции или образы приложения.

`platform-import.json` хранит подготовленные данные, `platform-import-result.json` — сведения о целевом стенде и результате. Видео отдаются с поддержкой HTTP Range. Markdown просмотрщика уроков поддерживает локальные изображения и ссылки с разрешёнными HTTP/HTTPS URL; HTML и исполняемые URL не интерпретируются.

Все 45 заданий перенесены как материалы для самостоятельной работы. В каждом явно указано, что автоматическая проверка не настроена, а отметка прохождения означает ознакомление. Вымышленные правильные ответы не добавлялись. Для проверяемых тестов преподавателю нужно задать ключи и адаптировать сопоставления, таблицы, сортировку, пропуски и множественный выбор.

Проверено: сборка frontend, 193 теста API-клиента, браузерный тест Markdown (изображения, ссылки, запрет исполняемых URL и сырого HTML). На импортированном курсе проверены бесплатная запись через UI, воспроизведение видео 1280×720, отображение изображения, сохранение прогресса, сообщение о самостоятельной работе и отсутствие горизонтальной прокрутки при ширине 390 px. Все 60 медиафайлов проверены через HTTP: размеры и типы содержимого совпадают, видео поддерживает Range (206).
