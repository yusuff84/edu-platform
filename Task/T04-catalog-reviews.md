## Что сделать

### Каталог (`Catalog.tsx`, `CourseCard.tsx`)

1. Карточка: название, описание (обрезка), цена через `formatPrice`,
   рейтинг (`avgRating`, `ratingsCount`), ссылка на `/courses/:slug`.
   Никаких полей, которых нет в `CourseItem` (`coverUrl`, `status`,
   `teacherName`) — не рендерить пустышки.
2. Поиск с дебаунсом (300 мс), синхронизация с query-параметром `?q=`
   через `useSearchParams` — ссылку можно передать.
3. Пагинация по `total`/`page`/`limit`; состояние «показаны все N курсов».
4. Состояния: загрузка (скелетоны), пусто с подсказкой сбросить фильтр,
   ошибка с кнопкой «повторить».

### Страница курса (`Course.tsx`)

5. Ответ `getCourse` приходит как `{ course, modules }` — разворачивать
   корректно (после T01 клиент уже нормализует; проверь и не ломай).
6. Программа курса: модули → уроки, с количеством уроков,
   без раскрытия `correct`-ответов.
7. Рейтинг: `avgRating` + «N отзывов» (`ratingsCount`).
8. Кнопка покупки:
   - не авторизован → ведёт на `/login`;
   - `priceCents === 0` → покупка происходит мгновенно;
   - иначе → `enroll()`; при `redirectUrl` — переход по нему;
   - обработать `409` («уже есть активная запись») — не ошибкой, а сообщением.
9. Если есть активная запись — кнопка «перейти к обучению» на `/learn/:id`.
   Активную запись определять через `myCourses()` (после T01 это массив).
10. Черновик/на модерации (виден только автору/админу) — понятный баннер,
    показывать `moderationComment`, если курс отклонён.

### Отзывы (`Reviews.tsx`)

11. Список из `listReviews()` — после T01 это массив.
    Поля: `rating` (звёзды), `body`, `createdAt` через `formatDate`.
12. «Ваш отзыв» определять по `studentId === me.id` (не по email!).
13. Форма отправляет `{ rating, body }`.
14. Состояния: загрузка, пусто («отзывов пока нет»), ошибка,
    успех после отправки, `409` («вы уже оставляли отзыв»),
    `403` («нужна активная запись на курс»).
15. Показывать форму **только** если: пользователь вошёл,
    запись активна, и своего отзыва ещё нет. Остальным — текст-объяснение.
16. Доступность: радиогруппа оценки с клавиатурным управлением,
    `aria-live` для результата отправки.

## Критерии приёмки

- [ ] `npx tsc --noEmit` в `frontend/` проходит
- [ ] В файлах нет слов `reviewsCount`, `coverUrl`, `authorEmail`,
      `text:`, `myQuery.data.length`
- [ ] Отправка ответа возвращает `201` (проверь в DevTools — payload именно `{rating, body}`)
- [ ] Пагинация каталога работает, счётчик «показано N из M»
- [ ] Пустые состояния есть у каталога, отзывов и страницы курса
- [ ] CSS — только в `frontend/src/styles/catalog.css`
- [ ] Все строки — по-русски, через `t()`; новых ключей не выдумывать
