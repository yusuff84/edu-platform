# T44 — Runner: прогон тестов с интерпретаторами (runner)

**Волна:** P5 · **Ветка:** `task/T44-runner-tests` · **Worktree:** `wt/t44`

## Зачем

Честный список T20: python/js-тесты runner пропускаются без `python3`/`node`,
а «полный» прогон возможен только в build-этапе Dockerfile (слой может быть
закэширован — свежесть не гарантирована). Нужен воспроизводимый прогон,
честный отчёт о результате и короткая команда в README.

## Что сделать

1. Прогнать тесты в контейнере с интерпретаторами (ядро работы), из корня worktree:

```powershell
docker run --rm -v "${PWD}\runner:/src" -w /src golang:1.24-bookworm sh -c "apt-get update -qq && apt-get install -y -qq --no-install-recommends python3 nodejs >/dev/null && go vet ./... && go test ./... -count=1 -v"
```

2. Разобрать вывод: какие тесты были SKIP в чистом `golang`-образе и стали PASS;
   есть ли FAIL — если да, починить (`runner/main.go`, `runner/main_test.go`;
   только `runner/**`).
3. Убедиться, что с интерпретаторами проходят: реальный запуск python и js
   (включая прогон тестов), общий бюджет времени, лимит вывода, семафор
   конкурентности, статическая проверка htmlcss. Если чего-то из списка нет
   в тестах — добавить тест (без новых зависимостей).
4. Короткий раздел «Проверка runner» в `README.md` (рядом с «Тесты и QA»):
   команда выше и одна фраза, зачем она нужна.

## Правила волны

- Работать только в своём worktree; коммит — в свою ветку `task/T44-runner-tests`.
- Править только: `runner/**` (код, тесты, Dockerfile — если реально нужен),
  `README.md` (только новый раздел), отчёт `runner/tests/T44-runner-tests.md`.
- `backend/**`, `frontend/**`, `Task/**`, `specs/**` — не трогать.
  Новых зависимостей проекта нет (пакеты apt — окружение теста, не проект).

## Проверка

Вывод `go test -count=1 -v` приложить в отчёт: для тестов с интерпретаторами
не должно остаться `SKIP` (кроме честно невозможных — объяснить), `FAIL` — нет.

## Отчёт

`runner/tests/T44-runner-tests.md`: команда, список тестов с итогами
(было/стало), что починено или добавлено, честный список непроверенного.
