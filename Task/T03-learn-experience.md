**Ключ сессии:** `T03-learn-experience`
**Волна:** 2 (после T01, T02) · **Слой:** frontend
**Приоритет:** P0 — страница падает с `TypeError`, вердикт всегда «не зачтено»

## Проблема

`frontend/src/pages/Learn.tsx` и `frontend/src/components/LessonView.tsx`:

- `Learn.tsx:13` — `(myQuery.data ?? []).find(...)` падает: `myCourses()` возвращает
  объект-конверт, а не массив (чинится в T01, здесь — потребление);
- `Learn.tsx:18-19` — `getCourse(courseId)` передаёт **UUID**, а backend
  ждёт **slug** (`handler/courses.go:131-132`) → всегда `404`;
- `Learn.tsx:48` — читает `res.accepted`, бэкенд отдаёт `passed`
  → вердикт «Не зачтено» даже при успехе;
- `LessonView.tsx:103-158` — code-урок **не показывает условие задачи и шаблон**;
- `LessonView.tsx:57-101` — `CodeEditor` стартует с пустым `useState('')` (`:64`),
  игнорируя `codeTask.template`;
- объяснение к правильному варианту квиза (`explanation`) **никогда не рендерится**
  (FR-010 / `spec.md` US3-SC2 не выполнен);
- нет состояний загрузки/ошибки/пустого списка уроков.

## Что сделать

1. **Починить получение курса.** У `Learn.tsx` есть `courseId` (из URL).
   Варианты: (а) брать `slug` из элемента `myCourses()`, найденного по `id`;
   (б) если элемент не найден — показать «нет доступа» вместо запроса.
   Реализуй (а) с фолбэком на понятное сообщение. Не запрашивай
   `getCourse()` с UUID.
2. **Вердикт.** Использовать `passed`/`completed`/`percent`/`nextLesson`
   согласно контракту. Показать `message` от сервера при провале.
3. **Список уроков** сгруппировать по модулям, отметить завершённые,
   показать прогресс (`percent`) и «следующий урок» с переходом.
4. **Code-урок:**
   - выводить условие (если оно в `bodyMd`) и **шаблон кода**;
   - инициализировать редактор значением `codeTask.template`;
   - кнопка «сбросить к шаблону»;
   - отправлять `code` + `language` на `completeLesson`;
   - показывать результат по тестам;
   - при `502` (runner недоступен) — понятное сообщение, не краш.
5. **Quiz-урок:**
   - варианты ответа из `quiz.questions[].options`;
   - `quizAnswers: { [questionId]: index }`;
   - **после ответа показывать `explanation`** для каждого вопроса;
   - блокировать повторную отправку до выбора всех ответов.
6. **Live-урок:** `liveUrl` + `startsAt`; если эфир в будущем — таймер/дата;
   если ссылка есть — кнопка перехода.
7. **Video/text-урок:** `bodyMd` (простой markdown → абзацы/списки/код,
   без новых зависимостей — напиши маленький безопасный рендерер или
   используй уже существующие примитивы) и `videoUrl`.
8. **Состояния:** загрузка, ошибка сети, 403 «нет активной записи»,
   пустой курс, урок не найден. Никаких необработанных исключений.
9. **Клавиатурная доступность** (принцип VI конституции): фокус на вариантах
   квиза, `aria-label` на кнопке проверки, видимый фокус.
