# Формат файлов курса «Системное администрирование: база»

Каждый файл partN.py содержит переменную:

```python
MODULES = [
  {
    "title": "Как устроен компьютер",          # без номера — номер подставит загрузчик
    "lessons": [
      {"title": "2.1 Процессор, память и накопители", "kind": "text", "body": "<markdown>"},
      ...
      {"title": "2.6 Практикум: устройство компьютера", "kind": "quiz",
       "questions": [{"text": "...", "options": ["...", "...", "..."], "correct": 1}, ...]},
    ],
  },
  ...
]
```

Правила разметки body (плеер понимает только это): абзацы, `## ` и `### ` заголовки, списки `- ` и `1. `,
`> ` цитаты, `**жирный**`, `*курсив*`, `` `код` `` в строке и блоки кода ``` ``` ```. Таблиц и картинок нет.
Не начинать body с заголовка `# ` (название урока выводится отдельно).

Тесты: ровно один верный вариант (`correct` — индекс), 3–4 варианта, правдоподобные, но однозначно неверные
дистракторы, без «все перечисленное», без подсказок в формулировке; верные ответы по разным позициям.
Тест засчитывается, только если все ответы верны.
