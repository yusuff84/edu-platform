# Оформление курса «Системное администрирование: база»: уроки, схемы, видео

Цель — чтобы теория **быстро усваивалась**: человек за 30 секунд понимает суть урока, глаз цепляется
за главное, сложное объяснено картинкой, а в начале каждого модуля есть видеообзор с озвучкой.

## 1. Разметка текста урока (что умеет сайт)
Рендерер — `frontend/src/components/Markdown.tsx` (читать не обязательно). Поддерживается:
- `## Заголовок раздела`, `### Подзаголовок`; абзацы; списки `- …` и `1. …` (нумерованный = шаги, рисуется кружками);
- `**жирный**`, `*курсив*`, `` `код` ``, блоки ``` ```; `==маркер==` (жёлтое выделение — для 1–2 ключевых фраз на урок);
- `[[Ctrl]] + [[C]]` — клавиши; `---` — разделитель;
- таблицы: `| Колонка | Колонка |` + строка `|---|---|` (на телефоне сами становятся карточками; 2–4 колонки, коротко);
- рисунок: отдельным абзацем `![Подпись под рисунком](media/имя.png)`;
- выноски — цитата, первая строка которой `> [!ТИП] Необязательный заголовок`, дальше строки `> …` с любой разметкой
  (списки, код, таблица). Типы: `SUMMARY` (Главное), `TERM` (Термин), `TIP` (Совет), `IMPORTANT` (Важно),
  `WARNING` (Внимание), `DANGER` (Опасно), `NOTE` (Заметка), `EXAMPLE` (Пример), `PRACTICE` (Попробуйте сами),
  `CHECK` (Проверьте себя).

## 2. Шаблон урока (обязательные элементы)
1. В самом начале — `> [!SUMMARY] За 30 секунд` с 3–4 пунктами: что узнаем / главная мысль.
2. Короткое вступление (1–3 предложения: зачем это админу, жизненная ситуация).
3. Разделы `##` по 2–5 коротких абзацев (до 3–4 строк каждый). Длинные абзацы — дробить.
4. Ключевые термины при первом появлении — **жирным**; для 1–3 главных терминов урока — выноска `TERM`.
5. Сравнения (что чем отличается, варианты, параметры) — таблицей. Последовательность действий — нумерованным списком.
6. Команды — блоками кода; пояснение к команде — строкой выше, не в той же строке (на телефоне длинные строки уезжают).
7. Подводные камни — `WARNING`/`DANGER`; хитрости — `TIP`; реальный пример из офиса — `EXAMPLE`.
8. Минимум 1 схема/иллюстрация на модуль там, где она реально помогает (сеть, загрузка ПК, права, дерево каталогов…).
9. В конце — `> [!PRACTICE]` (что сделать руками, 2–4 пункта) и/или `> [!CHECK]` (2–3 вопроса с ответами *курсивом*).
Не перебарщивать: 3–6 выносок на урок, маркер — 1–2 раза. Тон — дружелюбный, на «вы», без воды.
Факты не выдумывать; то, в чём не уверены (подписи интерфейса, сроки, коды), формулировать осторожно («в зависимости от версии»).

**Нельзя менять**: названия уроков и модулей, порядок и количество уроков, тесты (вопросы `quiz`) — по названиям
уроков работает обновление на сайте. Структура данных частей — как в `FORMAT.md`.

## 3. Схемы и иллюстрации
- Исходник — HTML в `sysadmin/media_src/<имя>.html` по образцу `_template.html` (всё внутри `#art`, ширина 1600,
  светлый фон, крупный текст ≥ 24px, цвета сайта; можно inline-SVG). Имя файла — латиницей, `m09-dhcp-flow`.
- Рендер: `cd frontend && node scripts/render-html.mjs ../scripts/course-content/sysadmin/media_src/<имя>.html ../scripts/course-content/sysadmin/media/<имя>.png`
- В уроке: `![Как компьютер получает адрес по DHCP](media/<имя>.png)`. Подпись — понятная, как подпись к рисунку в учебнике.
- PNG до ~400 КБ. Посмотрите результат (Read по png) — читается ли текст при ширине телефона.

## 4. Видео модуля (обзор с озвучкой)
Одно видео на модуль, 3–4,5 минуты, 10–14 слайдов. Сценарий — `sysadmin/videos/mNN.py` (NN — номер модуля 01..13):
```python
VIDEO = {
    'course': 'Системное администрирование: база',
    'footer': 'Модуль 9 · Сети: основы',
    'kicker': 'Модуль 9',
    'slides': [ {...}, ... ],
}
```
Макеты слайдов (поле `layout`) и их поля; в текстах слайдов можно `**акцент**` и `` `код` ``:
- `title`: `title`, `subtitle` — первый слайд;
- `points`: `title`, `items` (2–5 строк или `{'text','sub'}`), `columns: 2` для 6 коротких пунктов;
- `terminal`: `title`, `shell` (подпись окна), `lines` (строки: `$ `/`> `/`PS> `/`# ` — команда, `// ` — комментарий,
  `! ` — предупреждение, остальное — вывод; до 8 строк, до ~48 символов), `note: {'title','text'}` — по желанию;
- `compare`: `title`, `columns` (2–3 карточки `{'title','icon' (1 символ),'tone': 'good'|'bad'|'' ,'items': [...]}`), до 4 пунктов;
- `steps`: `title`, `items` (3–5 шагов, строка или `{'text','sub'}`);
- `term`: `kicker`, `term`, `definition`, `example`;
- `diagram`: `title`, `html` (небольшой HTML/SVG, белый текст на тёмном фоне слайда) — по желанию;
- `tip`: `tone` (`tip`|`warn`|`danger`|`important`), `text`;
- `summary`: `title` (по умолчанию «Главное»), `items` (3–5), `next` (что в следующем модуле).
Каждый слайд — поле `say`: что говорит диктор, **1–4 предложения**, живым разговорным языком, дополняет слайд, а не читает его.

**Правила озвучки (синтез речи читает их буквально):**
- **никакой латиницы**: Windows → «виндоус», Linux → «линукс», DHCP → «ди-эйч-си-пи», IP → «ай-пи», ping → «пинг»,
  ipconfig → «ай-пи-конфиг», sudo → «судо», PowerShell → «пауэршелл», Wi-Fi → «вай-фай»;
- **никаких цифр**: «сто девяносто два», «двадцать четвёртая маска»; IP-адреса целиком вслух не читать
  («адрес на слайде»); знаки `/ % → :` словами;
- короткие предложения, без скобок и списков через точку с запятой.
Сборщик проверит это сам и откажется собирать при ошибке.

Сборка: `cd scripts/course-content && python3 video/build_video.py sysadmin/videos/mNN.py --keep`
(≈1 минута; печатает длительность и размер; `--keep` оставляет PNG слайдов во временной папке — путь в выводе).
Посмотрите 3–4 слайда (Read по png): ничего не вылезает, крупно, читаемо. Размер ролика — до 5,4 МБ.
Затем в модуле части (`partN.py`) добавьте ключ `'video': 'videos/mNN.mp4'` — ролик встанет в первый урок модуля.
