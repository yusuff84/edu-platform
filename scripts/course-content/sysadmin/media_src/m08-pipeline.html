Конвейер: вывод одной команды — вход следующей

$ cat logins.txt | grep fail | sort | uniq -c
cat
выводит файл
olga ok
ivan fail
anna fail
ivan fail
olga ok
|→
grep fail
строки с «fail»
ivan fail
anna fail
ivan fail
|→
sort
сортирует

ivan fail
ivan fail
|→
uniq -c
считает повторы
1 anna fail
2 ivan fail
