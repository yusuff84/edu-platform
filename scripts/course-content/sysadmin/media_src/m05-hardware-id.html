Как читать «ИД оборудования»

PCI\VEN_10EC&DEV_8168&SUBSYS_…
ШинаPCI — устройство внутри компьютера, USB — подключено снаружи
ПроизводительVEN_10EC — Realtek
МодельDEV_8168 — сетевой контроллер
USB\VID_046D&PID_C52B
У USB-устройств то же самое называется VID и PID. VID_046D — Logitech. Пару «производитель + модель» ищите в Microsoft Update Catalog.
