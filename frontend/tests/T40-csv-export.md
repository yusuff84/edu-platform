## Как устроена выгрузка

### Компонент `CsvExportButton`

Пропсы: `filename: string`, `headers: string[]`,
`loadRows: () => Promise<Array<Array<string | number | null>>>`,
`disabled?: boolean`. Кнопка: текст `admin.exportCsv`, `title` —
`admin.exportCsvHint`. Внешний `disabled` в компоненте реализован, но страницы
его не передают: единственная блокировка кнопки — своя, на время выгрузки
(`busy`), чтобы нельзя было запустить вторую выгрузку поверх первой.

- `toCsv` — экспортируемая чистая функция без DOM: `export function toCsv(
  headers: string[], rows: Array<Array<CsvCell>>): string`, где
  `CsvCell = string | number | null`. Её сможет покрыть T37-подобный набор тестов.
- Формат: BOM `\uFEFF` в начале (Excel корректно открывает UTF-8), разделитель
  `;`, каждое поле в кавычках, внутренние кавычки удваиваются (`"` → `""`),
  `null`/`undefined` → пустое поле (`""`), строки разделяются CRLF, переводы
  строк **внутри** значений сохраняются (поле в кавычках).
- Скачивание: `new Blob([csv], { type: 'text/csv;charset=utf-8' })` →
  `URL.createObjectURL` → скрытая `<a download>` добавляется в документ,
  кликается и удаляется; ссылка ревокируется после клика (`setTimeout(…, 0)` —
  чтобы скачивание успело начаться). Библиотек нет.
- Сообщения под кнопкой: успех → `admin.exported` (`role="status"`), ошибка →
  текст ошибки (`role="alert"`), пустой набор → `admin.exportEmpty`
  (нейтральный стиль, файл не создаётся). Ошибки разбираются как на страницах:
  403 → `cabinet.needRole`, 401 → `error.needLogin`, прочие `ApiError` → текст
  бэкенда или `common.error`, `TypeError` → `error.network`.

### `AdminUsers.tsx`

- Выгрузка идёт по **применённым** фильтрам (`q` после debounce, `role`,
  `status`) — тем же параметрам, что у запроса списка.
- Постранично `limit=100`, цикл до `total`; жёсткий потолок — **не более
  50 страниц (5000 строк) за клик**. Цикл останавливается на неполной странице,
  при `rows.length >= total` или на 50-й странице.
- Колонки (7): Email, Имя, Роль, Статус, Дата регистрации, Курсы, Записи.
- Заголовки: `adminUsers.colEmail`, `adminUsers.colName`, `adminUsers.colRole`,
  `adminUsers.colStatus`, `profile.registered` («Дата регистрации» — ключ
  профиля), `adminUsers.colCourses`, `adminUsers.colEnrollments`.
- Значения: роль/статус — словарными подписями (`adminUsers.role*` /
  `adminUsers.status*`), дата — `formatDate`, пустое `displayName` — пустое
  поле (не «—»).
- Имя файла: `users-<ГГГГ-ММ-ДД>.csv` (локальная дата, `csvDateStamp`).

### `AdminCourses.tsx`

- Те же правила цикла (limit=100, ≤50 страниц) по фильтрам `q`/`status`.
- Колонки (10): Slug, Название, Преподаватель, Статус, Цена, Модулей, Уроков,
  Учеников, Создан, Обновлён.
- Заголовки: `adminCourses.colTitle`, `adminCourses.colTeacher`,
  `adminCourses.colStatus`, `adminCourses.colPrice`, `course.modulesCount`
  («Модулей»), `adminCourses.colLessons`, `adminCourses.colStudents`,
  `adminCourses.colUpdated`; «Slug» и «Создан» — короткие подписи прямо в CSV
  (подходящих ключей нет; это данные, а не интерфейс).
- Значения: статус — словарной подписью (`teach.status*`), цена —
  `formatPrice` (0 → «Бесплатно», иначе рубли через `formatMoney`), даты —
  `formatDate`.
- Имя файла: `courses-<ГГГГ-ММ-ДД>.csv`.

Существующее поведение страниц не тронуто: фильтры, debounce, пагинация,
сброс страницы, модерация (архив/снятие с публикации), отзывы, удаление
пользователя, локальные сообщения — как было.

## Ограничения

- **Потолок 5000 строк** (50 страниц × 100): если `total` больше, файл
  обрезается молча — подходящего ключа словаря для предупреждения об
  усечении нет, а `ru.json` править нельзя. Лишний запрос данных не портит:
  выгружаются первые 5000 строк текущей выборки.
- Кодировка — UTF-8 с BOM, разделитель — `;` (русский Excel по умолчанию);
  поля всегда в кавычках, поэтому `;` и переводы строк в названиях/именах
  безопасны.
- Выгружаются применённые (debounced) фильтры: если пользователь печатает
  запрос и сразу жмёт кнопку до конца паузы 300 мс, выгрузка возьмёт прежний
  `q`. Это осознанно — кнопка выгружает то, что видно в списке.
- Пустой набор: файл не создаётся, показывается `admin.exportEmpty`.
- Кнопка блокируется только на время выгрузки; параллельные мутации таблицы во
  время выгрузки не блокируются (запросы только читающие).
