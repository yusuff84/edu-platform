# T86 — страница модерации Q&A (фронтенд)

**Ветка:** `task/T86-admin-qa-ui`  
**Worktree:** `wt/t86`  
**Контракт:** `Task/00-api-contract.md`, раздел T85 (заморожен).

## Что сделано

- `frontend/src/api/adminConsole.ts` — добавлены типы `AdminQuestion`,
  `AdminAnswer`, `AdminQuestionsResponse`, `AdminQuestionsQuery` и функции:
  - `listAdminQuestions(query)` — `GET /admin/questions` через `apiFetch` +
    `buildQuery`, пустые фильтры не отправляются;
  - `deleteAdminQuestion(courseId, questionId)` и
    `deleteAdminAnswer(courseId, questionId, answerId)` — тонкие обёртки над
    уже существующими `deleteQuestion`/`deleteAnswer` из `client.ts`; путь и
    кодирование id не дублируются, `client.ts` не изменялся.
- `frontend/src/pages/AdminQa.tsx` (новый) — страница `/admin/qa`:
  - заголовок/подзаголовок и ссылка «Назад в админку»;
  - фильтры: поиск с debounce 300 мс, курс (`listAdminCourses`), урок
    (загружается по выбранному курсу через `getTeacherCourseDetail`);
  - URL-состояние `courseId`/`lessonId`/`q`/`page` (ссылка шарится, «Назад»
    браузера работает); осиротевший `lessonId` очищается;
  - карточки вопросов: курс (ссылка на витрину по `courseSlug`), урок
    (ссылка на `/admin/courses/:id`), автор, дата, текст, число ответов,
    «Развернуть»/«Свернуть» (`aria-expanded`/`aria-controls`);
  - раскрытые ответы: бейдж роли (`p9.qa.teacherBadge` для преподавателя,
    `p10.qa.student` для ученика), автор, дата, текст, «Удалить ответ»;
  - удаление вопроса/ответа с инлайн-подтверждением, pending-состоянием
    (`aria-busy`), success-уведомлением (`aria-live`) и ошибкой рядом с
    карточкой; после успеха запись сразу убирается из кэша и вызывается
    `invalidateQueries`; удаление последней карточки страницы возвращает на
    предыдущую;
  - состояния loading (skeleton), error (текст + повтор), empty, пагинация;
  - адаптивная вёрстка, `useSeo`.
- `frontend/src/styles/adminQa.css` (новый) — стили только страницы Q&A на
  переменных дизайн-системы, брейкпоинты 880/560 px; общий `styles.css` не
  изменялся.
- `frontend/src/app/router.tsx` — lazy-импорт `AdminQa` и маршрут
  `/admin/qa` с `RequireRole roles={['admin']}`.
- `frontend/src/pages/Admin.tsx` — ссылка «Вопросы и ответы» в навигации
  админки (см. отклонение 2).
- `frontend/tests/api-contract/admin-qa.test.mjs` (новый) — 11 тестов:
  query-строка `courseId/lessonId/q/page/limit`, пустые фильтры, URL-кодирование,
  400/404 → `ApiError`, форма ответа с веткой `answers`, DELETE вопроса и
  ответа (204, без тела, кодирование id).
- `ru.json` и бэкенд не изменялись. Использованы только существующие ключи
  `p10.qa.*`, `p9.qa.teacherBadge`, `common.*`, `admin.*`, `error.*`,
  `cabinet.*`.

## Отклонения

1. **API-модуль.** Постановка предлагает новый `api/adminQuestions.ts`, но
   головное задание требует разместить типы и функции в
   `api/adminConsole.ts` рядом с остальным админским API. Сделан второй
   вариант; отдельный модуль не создавался.
2. **`Admin.tsx`.** Файл указан в постановке как запрещённый, но головное
   задание явно требует ссылку в навигации админки. Ссылка добавлена одной
   строкой, остальная страница не менялась.
3. **Кнопка обновления.** Отдельного замороженного ключа «Обновить» в
   `p10.qa.*` нет; используется `common.retry` («Повторить»). Новые ключи не
   добавлялись.
4. **Источник уроков.** Для фильтра по уроку используется существующий
   `getTeacherCourseDetail` (доступен админу), без новых эндпоинтов.
5. **Бейдж роли admin.** Для роли `admin` отдельного ключа нет, поэтому
   бейдж не рисуется (ответ всё равно виден в списке).
6. **Тестовая сборка.** `npm run test:build` собирает только `client.ts`,
   поэтому новый тест сам собирает `adminConsole.ts` через Vite в
   `.tmp-api-test/admin-console` (каталог в `.gitignore`) и импортирует ESM.

## Открытые вопросы

- После слияния T85 стоит проверить страницу на реальных данных: вопросы без
  ответов, удаление единственного вопроса на последней странице, поведение
  при 403/404 от бэкенда.
- Если понадобится бейдж для роли `admin` или отдельная подпись кнопки
  «Обновить», потребуется аддитивный ключ в `ru.json` (вне рамок T86).
- Фильтр курсов показывает первые 100 курсов (максимум контракта
  `listAdminCourses`); при большем числе курсов нужен поиск по справочнику.
