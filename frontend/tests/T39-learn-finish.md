## Что изменено

### `pages/Learn.tsx` (421 → 466 строк)

1. **Кнопка «Следующий урок» после успешного вердикта.**
   Добавлен расчёт `passedNextLesson` (стр. ~166–185): при `verdict?.passed`
   цель выбирается по цепочке:
   1) серверный `progress.nextLessonId` из `course-progress`, если такой урок есть
      в программе курса (`flatLessons.find`);
   2) `nextLesson` из ответа `complete` — тоже серверное значение;
   3) линейный следующий `flatNext` — как для случая провала.
   Если следующий урок не найден ни одним способом (последний урок / курс
   пройден) — кнопки нет.
   В рендере (стр. ~438–448) вместо прежней ссылки `lesson.next` (показывалась
   только при непустом `verdict.nextLesson`, вела на тот же серверный урок)
   выводится ссылка с текстом `learn.nextLesson`:
   `«Следующий урок: {title}»` → `/learn/{courseId}/{lessonId}`.

   Расширение приоритета относительно буквы ТЗ (там два уровня:
   `progress.nextLessonId` → `flatNext`): между ними добавлен уровень (2).
   Причины: сразу после `complete` запрос прогресса инвалидируется и
   перечитывается, и до ответа в кэше лежит **старый** `nextLessonId` — обычно
   это только что пройденный урок (в этом окне он пропускается guard'ом
   `id !== activeLesson.id`); `nextLesson` из `complete` — тот же серверный
   расчёт на момент завершения, он даёт верную цель сразу и корректно
   обрабатывает прохождение не по порядку, когда линейный следующий уже пройден.
   После перечитывания прогресса приоритет 1 совпадает с уровнем 2, так что
   итоговое состояние не расходится с ТЗ.

2. **Панель завершения курса при `progress.percent === 100`** (стр. ~334–350).
   Размещена **над** блоком `.lesson-shell` (после полосы прогресса), навигацию
   по урокам и содержимое урока не перекрывает. Содержимое:
   заголовок `learn.courseFinished`, текст `learn.finishedHint`, кнопка
   `learn.leaveReview` → `/courses/{slug}` (там форма отзыва; `slug` — из
   `meCourse.course.slug`). Если `slug` пуст — ссылка на `/me` с текстом
   `common.back`. Панель помечена `role="status"` (как и вердикт — скринридер
   узнаёт о финише после перечитывания прогресса).

3. **T30 не нарушен**: `percent`, `nextLessonId`, `completedLessonIds` — только
   из ответа `course-progress`; никаких локальных «дорисовок»; панель и кнопка
   используют исключительно серверные данные. Ничего не инвалидируется сверх
   прежнего (`course-progress`, `my-courses`, `me-courses`).

Не тронуто: вердикт провала и текст ошибки, состояния загрузки/ошибки/отказа в
доступе, `sr-only`-метки («Урок пройден»), разметка сайдбара, блок «Продолжить»
для случая провала.
