# T80 — Фронтенд: блок «Похожие курсы» на странице курса

**Ветка:** `task/T80-similar-courses-ui` · **Worktree:** `wt/t80`
**Волна:** P9 · **Контракт:** T79, раздел «Волна P9» в `Task/00-api-contract.md`

## Что сделано

1. **API-клиент** (`frontend/src/api/client.ts`):
   - добавлен `getSimilarCourses(courseId, limit?) → Promise<CourseItem[]>`;
   - запрос `GET /courses/{id}/similar?limit=N`, `courseId` кодируется через
     `encodeURIComponent` (это UUID, но контракт требует безопасности пути);
   - конверт `{items,total}` распаковывается в массив `items`;
   - `limit` необязателен: при `undefined` query-параметр не отправляется;
   - существующие функции не менялись (обратная совместимость).

2. **Типы** (`frontend/src/api/types.ts`):
   - в `Course` добавлено аддитивное `category?: string` — бэкенд отдаёт
     `category` во всех видах курса (`repo.Course`), но фронтовый тип его
     не описывал; без этого нельзя передать `course.category` в блок.

3. **Компонент** (`frontend/src/components/SimilarCourses.tsx`, новый):
   - пропсы `courseId: string`, `category?: string`;
   - `useQuery` с ключом `['similar-courses', courseId]`, `limit=4`, `retry: false`;
   - заголовок «Похожие курсы» (`p9.similar.title`);
   - сетка карточек на `CourseCard` — компонент не изменялся;
   - ссылка «Все курсы категории» (`p9.similar.all`) на `/?category=<category>`;
     при пустой категории ссылка не рендерится;
   - загрузка — скелетон из 4 плейсхолдеров высотой с плитку, со скрытым
     `role="status"` текстом `common.loading`;
   - ошибка или пустой `items` — компонент возвращает `null`, блок не виден;
   - стили подключаются импортом `../styles/similar.css`.

4. **Страница курса** (`frontend/src/pages/Course.tsx`):
   - точечная аддитивная правка: импорт и `<SimilarCourses courseId={course.id}
     category={course.category} />` сразу после `<Reviews />` в левой колонке;
   - существующая вёрстка и соседние блоки не переформатированы.

5. **Стили** (`frontend/src/styles/similar.css`, новый):
   - скоуп `.similar-courses`, используются токены дизайн-системы
     (`--brand`, `--brand-dark`, `--line-soft`, `--sp-*`);
   - шапка с заголовком и ссылкой (flex + wrap), сетка 2×2 из четырёх карточек
     в колонке страницы курса, одна колонка на экранах ≤ 640px;
   - скелетон с пульсацией и отключением анимации при
     `prefers-reduced-motion: reduce`;
   - чужие css-файлы не изменялись.

6. **Тесты** (`frontend/tests/api-contract/similar-courses.test.mjs`, новый),
   5 кейсов:
   - запрос с `limit=4` — метод, путь, query без лишних параметров;
   - вызов без `limit` — query пустой;
   - URL-кодирование id (кириллица, пробел, слэш, `?`) в пути и сыром URL;
   - пустой `items` → `[]`;
   - непустой ответ → массив `CourseItem[]` из `items` (конверт не
     протекает в результат).

   i18n: используются только готовые ключи `p9.similar.title`,
   `p9.similar.all` и `common.loading`; `ru.json` не менялся.

## Отклонения

- В `Course` добавлено поле `category?: string` (файл `types.ts` входит в
  разрешённые). Это не изменение контракта, а синхронизация типа с уже
  существующим ответом бэкенда; без него постановка («передайте
  `course.category`») не типизируется.
- Ссылка «Все курсы категории» скрывается, если `category` пустая: вести в
  `/?category=` без значения бессмысленно. Для курсов бэкенд отдаёт `other`
  по умолчанию, так что на практике ссылка есть.
- Сетка сделана в 2 колонки (2×2 для лимита 4), а не `repeat(auto-fill)`:
  левая колонка страницы курса — около 714px внутри панели, четыре карточки
  в ряд там получаются слишком узкими; на ≤ 640px — одна колонка.
- Ошибки запроса намеренно не показываются (по постановке) — блок просто
  отсутствует, страница курса остаётся рабочей.

## Открытые вопросы

- Бэкенд T79 в этом worktree ещё не влит (идёт параллельно). До его появления
  `GET /courses/{id}/similar` будет отвечать 404, и блок просто не отрисуется —
  это штатное поведение по постановке. После слияния T79 нужен смоук на
  реальной странице курса.
- Проверка вёрстки выполнена сборкой и типами; визуальный смоук (2×2, мобильная
  одна колонка, скелетон) стоит сделать при приёмке волны P9 в браузере.
