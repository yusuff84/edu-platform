# skillex.space — задачи по итогам аудита (21.11.2026)

Аудит: мобильная вёрстка (22 экрана × 360/390 px, скриншоты + автопроверки),
сквозной сценарий ученика на телефоне, код бэкенда, раннера и деплоя.
Ветка с исправлениями фронтенда: `mobile-ux`.

Приоритеты: **P0** — чинить сейчас (теряем пользователей/данные/безопасность),
**P1** — ближайший спринт, **P2** — плановый долг. Размер: S ≤ 1 дня, M ≤ 1 недели, L — больше.
